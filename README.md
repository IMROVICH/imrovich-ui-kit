Тёмное стекло, золотой неон, плавные анимации и 12 переключаемых тем. Копируй — вставляй — используй.

---

## ✨ Что внутри

- 🎨 **12 цветовых тем** — Золото, Роза, Фиолет, Изумруд, Сапфир, Рубин и другие
- 🧊 **Glassmorphism** — размытое стекло с мягкими тенями
- ⚡ **Ноль зависимостей** — только чистый CSS + ~100 строк опционального JS
- 📱 **Адаптив** — от 320px до 4K
- ♿ **Доступность** — `:focus-visible`, семантическая разметка
- 🎭 **21 компонент** — кнопки, карточки, инпуты, модалки, тултипы, таймлайн, FAQ и другие

## 📦 Компоненты

| Категория | Что есть |
|-----------|----------|
| **Кнопки** | `btn-primary`, `btn-ghost`, `btn-sm`, `btn-icon`, disabled |
| **Формы** | `glass-input`, `glass-input` textarea/select, `toggle` |
| **Карточки** | `glass`, `demo-card`, hover-эффекты |
| **Бейджи** | базовый, `ok`, `danger`, `info` |
| **Навигация** | `tabs`, `top-nav`, `tooltip-host` |
| **Обратная связь** | `toast`, `demo-modal`, `progress`, `skeleton`, `demo-pulse` |
| **Структура** | `demo-timeline`, `demo-faq`, `demo-avatar` |
| **Утилиты** | 12 тем, ripple-эффект, кнопка «Копировать» |
